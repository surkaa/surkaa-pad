# 压缩包内文件预览

ZIP / 7z 的目录仍按 Range 读取。打开文件时，前端传递原始条目下标、路径、长度及目录读取时的对象 ETag；下标才是身份，不能以文件名查找（允许同名条目）。

## 数据流程

1. 后端持有存储操作锁，校验对象 ETag，排队执行单个解压任务。
2. ZIP 定位目标文件；7z 解码目标所在的整个块，非目标内容丢弃，进度按完整块的解码字节数统计。
3. 目标输出用独立随机密钥分块 AES-GCM 加密写入应用临时缓存；不使用压缩包内路径创建文件，不改写压缩包或日记附件。
4. 读到 EOF，完成压缩格式的 CRC / 认证检查，再次检查源对象 ETag。失败或取消时丢弃临时输出。
5. 成功后发布独立、不可枚举的单文件 capability URL；现有 PDF、JSONL 等预览器通过该 URL 读取，不取得压缩包的通用读取权限。

## 限制与生命周期

- 单个文件最多 256 MiB，目标块解码量最多 1 GiB，压缩数据读取预算 512 MiB。
- 预览缓存按明文长度计最多 512 MiB / 32 项；另有少量认证标签开销。正在播放/读取的资源仍计入预算，不能通过撤销令牌绕过预算。
- 一个后台解压任务，5 分钟超时，可取消。进度分别报告网络读取字节数、块解码百分比、最终校验阶段，不能把“正在读取网络”伪装成解压进度。
- 进度条在准备阶段固定为空，仅在解压阶段按实际解码字节数增长；校验阶段立即固定为满格，不使用循环等待动画。准备和校验阶段不显示解码字节比例。
- 解码字典上限 128 MiB，7z 编码目录在解码前检查目录长度及字典，目录最多 8 MiB。保留现有条目数量与路径深度限制。
- 不预览嵌套压缩包、符号链接、重解析点、删除标记；检查扩展名和文件签名。不开启自动解压目录、外部解压程序或命令执行。
- 未使用缓存 10 分钟过期，空间不足时淘汰最久未使用且未占用的资源。已撤销令牌不可新读，在途请求结束前保留密文和预算。
- 浏览器 HTML 使用独立的短期单文件令牌；关闭应用内预览后仍可在 10 分钟期限内读取，不允许枚举或自动读取其他压缩包条目。HTML 可运行脚本，需要用户明确同意；URL 路径不是独立安全源，隔离依赖不可猜测的逐文件 capability。
- 临时密钥不持久化、不参与云同步或改密。正常释放删除密文文件；异常退出遗留密文在下次启动清理，跨进程文件锁避免误删运行中的实例。

## 测试

本地测试覆盖 ZIP / 7z、AES 密码、损坏数据、非法路径/链接、取消、进度、加密临时缓存跨块读取、LRU/过期、令牌撤销、HTTP Range / HEAD、JSONL 分页及改密锁。

真实 OSS 用例强制 `surkaa-test` 和唯一 `rust-tests/…` 前缀，检查未加密与 CTR 加密压缩包的按需读取、原对象未改写、源 ETag 变化时拒绝复用。通过后清理本次对象，失败保留前缀供诊断。
