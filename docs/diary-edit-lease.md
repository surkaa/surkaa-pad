# 日记编辑占用与草稿保护

状态：实施中。此模块只协调云同步模式下的编辑，不改变日记正文的数据版本。

## 边界

- 占用记录与日记主文件分开；不记录读者或设备名称。其他设备可以只读打开。
- 编辑设备每 30 秒续期，占用有效期为 2 分钟。过期不会自动接管，必须由用户确认。
- 网络失败、占用丢失或正文版本变化时停止云端写入，未保存正文保留为本机加密草稿。
- 本地模式不需要跨设备占用。草稿不参与云同步，也不作为可淘汰的附件缓存。
- **这不是严格的分布式锁**：OSS PutObject 不支持目标对象的 If-Match 条件写入，启用或暂停版本控制后禁止覆盖头也不能保证互斥。检查与写入间仍存在窄并发窗口；旧版客户端也不会遵守占用。需要严格保证时应改用支持条件提交的协调服务或独立冲突版本，本版不实现。

## 打开与接管

```mermaid
flowchart TD
    A[打开日记] --> B{本地模式?}
    B -->|是| C[正常编辑]
    B -->|否| D[读取云端占用记录]
    D --> E{占用状态}
    E -->|不存在| F[写入本次编辑令牌并回读确认]
    E -->|其他会话未过期| G[只读打开]
    E -->|已过期| H[只读打开并提供接管按钮]
    E -->|读取失败或无法识别| G
    H --> I[用户确认接管]
    I --> F
    F --> J{回读仍是本次令牌?}
    J -->|否| G
    J -->|是| K[读取正文及其对应 ETag]
    K --> L[开启编辑与续期]
```

## 保存与恢复

```mermaid
flowchart TD
    A[正文发生变化] --> B[先保存本机加密草稿]
    B -->|失败| C[阻止云端保存并提示]
    B -->|成功| D[检查本次会话令牌及有效期]
    D --> E[检查正文 ETag 与编辑基线一致]
    E -->|一致| F[写入加密正文]
    F --> G[更新编辑基线]
    G --> H[仅清理已确认保存的那一版草稿]
    D -->|失效或不确定| I[转为只读并保留草稿]
    E -->|变化| I
    F -->|失败或响应丢失| I
    I --> J[重新打开或手动接管]
    J --> K[读取最新正文]
    K --> L[提示发现本机草稿，由用户决定是否恢复]
```

恢复草稿不是自动覆盖：先展示最新日记，再由用户确认恢复。草稿清理必须比较草稿版本，不能用旧保存结果删除更新的草稿。

## 续期、退出与后台恢复

```mermaid
stateDiagram-v2
    [*] --> ReadOnly: 未获占用
    [*] --> Editing: 获得占用并读到正文基线
    Editing --> Editing: 30 秒续期并回读确认
    Editing --> ReadOnly: 网络异常 / 过期 / 令牌变化 / 正文冲突
    ReadOnly --> Editing: 用户重新申请或接管，重新加载正文
    Editing --> Closed: 完成草稿保存及正在进行的操作后退出
    ReadOnly --> Closed: 草稿已落盘后退出
    Closed --> [*]
```

移动端恢复前台后不能依赖暂停前的计时器和内存状态；保存路径仍须重新检查云端占用和正文基线。释放只作用于自己的令牌，不能删除接管者的记录。释放与续期的网络写入同样受 OSS 非原子条件写入限制。

## 模块职责与写入覆盖

```mermaid
flowchart LR
    UI[日记详情与离开保护] --> Commands[Tauri 日记编辑命令]
    Commands --> Lease[编辑会话管理器]
    Commands --> Draft[本机加密草稿]
    Lease --> OSS[OSS 占用记录，绕过 LOS 缓存]
    Commands --> Store[受保护的 DiaryStore]
    Store --> Manifest[日记正文与附件元信息]
    Store --> Attachment[附件上传、删除及替换]
    Read[列表 / 搜索 / AI / 只读详情] --> Memory[只在内存升级旧结构，不静默回写]
```

正文自动保存、删除日记、附件新增/替换/删除/重命名、音波等静默元信息更新均属于写操作。只禁用编辑器不足以保护这些入口，必须在后端校验。附件下载和本地缓存不需要编辑占用。

占用文件是临时控制对象：不加入日记附件列表、不迁移为业务数据、不重新加密为永久数据。改密与本地草稿的协调必须避免产生无法解密的草稿。

## 验证清单

- 无占用、有效他人占用、过期手动接管、续期、释放及损坏记录。
- 旧会话失效后不得借用新会话资格写入；正文基线变化停止保存。
- 草稿加密、原子替换、保存失败、旧回执不清除新草稿、重启恢复。
- 只读打开不会触发迁移或音波等云端静默回写。
- 前端退出、切换日记、后台恢复和上传期间的状态切换。
- `surkaa-test` 唯一测试前缀真实 OSS 集成测试；通过后清理，失败时保留诊断对象。
